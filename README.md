# Model Optimization

Notebooks on three ways to make vision models smaller and faster in PyTorch: quantization, knowledge distillation and pruning. Each one measures accuracy before and after.

## What's inside

- `quantization/` holds the quantization notebook and a ResNet
- `knowledge_distillation/` holds the distillation notebook
- `pruning/` holds the pruning notebook

## How to run

```bash
pip install -r requirements.txt
jupyter notebook
```
